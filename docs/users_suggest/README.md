# User suggestions

Use the GitHub feature-request template for public ideas. Search existing
issues first and describe the user problem, proposed behavior, alternatives,
accessibility, privacy, fairness, monetization, and originality.

Do not submit copied commercial-game art, UI, audio, names, formulas, assets, or
confidential material. Do not include personal data, credentials, or private
security reports. Security reports follow `SECURITY.md`.

Suggestions are input, not promises. Optional BMC support never changes triage
priority or guarantees acceptance.
