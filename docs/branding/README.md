# CueVerse brand

Canonical name: CueVerse. Tagline: **Aim. Spin. Own the table.** Creator line:
**Made by the Sanskar**.

The visual language combines deep navy, tournament felt green, mint trajectory
accents, and warm gold focus/ball accents. The programmatic logo depicts a cue,
ball, and orbit to convey precision and a broad “verse” without resembling
commercial pool-game marks.

Do not use “8 Ball Pool” as the product name, imitate another game's icon/UI,
or use their table art, sounds, currencies, events, progression, or store
presentation. Keep package/asset references configurable before any rename.
