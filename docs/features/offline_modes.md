# Offline modes

## Practice

Uses the full physics table without turn/rule enforcement, preserves aim guide,
and allows rack reset. It is the calibration/tutorial environment.

## vs AI

Uses 8-ball or 9-ball state transitions. Player one is human; player two plans
from legal targets and shoots through the same physics world. Six difficulties
change planning/execution quality, not laws of physics.

## Local two-player

Pass-and-play on one device with shared table/rules. Turn changes derive from
shot outcomes. Full manual device match coverage, explicit called-pocket input,
and free ball-in-hand placement remain beta gates.

All current modes are offline. No network permission, account, matchmaking, or
remote opponent is used.
