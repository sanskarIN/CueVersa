# Feature status

## Implemented

- Responsive Android Flutter shell with original CueVerse branding.
- 8-ball/9-ball rack selection and documented WPA-inspired/casual profiles.
- Interactive offline practice, six-level AI, and local pass-and-play.
- Deterministic physics with aim, power, top/back/side spin, collisions, rails,
  pockets, scratch, break spread, and fixed-step tests.
- Local XP/level, match/win/streak/shot/pot/accuracy statistics.
- Challenges, weekly missions, achievements, tutorial, rule guide, and cosmetics
  foundation screens.
- Deep settings, English/Hindi runtime locale, accessibility modes, BMC support,
  open-source About, and hidden safe developer tools.

## Not yet shipped

Called-pocket input and free ball-in-hand placement; straight pool; time attack;
target/trick/solo-score modes; shot review/replay; full cosmetics inventory;
notifications; export/import; cloud save; private/friend rooms; matchmaking;
ranked service; tournaments; store/billing; ads; remote config.

Not-shipped features must not be presented as available. See `ROADMAP.md` and
`docs/upcoming/feature_status.md`.
