# Upcoming work

This folder distinguishes proposed, designed, implemented, tested, and released
capabilities. A roadmap entry is not a promise or shipped feature.

- `next.md`: exact near-term engineering sequence.
- `roadmap.md`: multi-horizon product direction.
- `feature_status.md`: capability/status matrix.
- `premium.md`: premium ideas and gates.

The authoritative current cursor is
`docs/development/continuation_ledger.md`.
