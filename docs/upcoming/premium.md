# Upcoming premium concepts

No premium feature is shipped. Candidates are original cosmetic packs,
fixed-content puzzle/campaign packs, advanced post-match statistics, optional
cloud backup, and hosted private-room enhancements.

Every candidate must keep offline core play useful, never affect ranked
physics/aim/time, disclose exact contents and price, support platform restore
and refunds, avoid fake urgency, preserve Apache-2.0 obligations, and pass the
decision gate in `docs/monetization/future_premium.md`.

BMC support is not a premium purchase and never unlocks these items.
