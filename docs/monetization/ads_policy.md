# Advertising policy

No ad SDK is present. If ads are ever proposed:

- never interrupt a turn, shot, rack, result-critical transition, tutorial
  control, or accessibility workflow;
- never obscure controls, imitate app/navigation buttons, auto-open a store, or
  use fake close affordances/countdowns;
- rewarded ads must be explicitly requested and grant only disclosed,
  noncompetitive convenience/cosmetic rewards;
- provide family/privacy review, consent where legally required, data-map/store
  disclosure, network failure behavior, frequency caps, and an honest ad-free
  option;
- exclude gambling, deceptive, adult, hateful, unsafe, or age-inappropriate ads;
- test slow/offline networks, rotation, background/resume, screen readers, large
  text, and provider failure.

An ad proposal stays disabled until policy, SDK license/security, performance,
privacy, and store compliance gates pass.
