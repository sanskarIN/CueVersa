# Store item design register

No in-app store is implemented. This candidate catalog prevents ad-hoc unfair
items if billing is proposed.

| Category | Allowed value | Ranked effect | Requirements |
|---|---|---|---|
| Cue skin | Visual material/shape within aim clarity | None | Original licensed art; contrast QA |
| Cloth/environment | Visual theme | None | Ball/pocket visibility and color-blind QA |
| Victory effect/trail | Brief cosmetic feedback | None | Reduced-motion/sound alternatives |
| Profile frame/title | Social cosmetic | None | Moderation-safe and localizable |
| Puzzle/campaign pack | Fixed authored content | None | Clear contents and offline rights |
| Advanced statistics | Analysis/convenience | None | No hidden competitive live data |
| Hosted room enhancement | Service capacity/features | None | Privacy/security/availability terms |

Disallowed: cash-out currency, wagering, purchasable match outcome, paid ranked
physics/aim/time, money loot boxes, misleading bundles, fake sales, and
donation-gated core gameplay.
