# Revenue model

## Available now

- Voluntary BMC support through an external user-initiated link.
- Community/open-source contribution and potential commissioned customization
  arranged independently with clear scope and license compliance.

## Candidates requiring separate implementation/review

- One-time ad-free/premium convenience bundle.
- Original cosmetic cue, cloth, environment, effect, profile-frame, or title
  packs with accessible visual clarity.
- Fixed-price campaign, puzzle, trick-shot, or advanced-statistics packs.
- Optional hosted private-room/cloud features priced for service operating cost.
- Sponsorship that is clearly disclosed and never inserted into active shots.

No revenue forecast is promised. Each candidate needs cost, store fee/tax,
support/refund, art/license, server, privacy, family-policy, accessibility, and
fairness analysis before approval.
