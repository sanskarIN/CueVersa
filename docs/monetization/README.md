# Ethical monetization

Current CueVerse includes only an optional external Buy Me a Coffee link. It
has no ads, billing SDK, premium currency, purchases, subscriptions, loot boxes,
cash wagering, or paid competitive advantage.

Future revenue must preserve Apache-2.0 obligations, honest pricing, family
safety, platform policy, privacy, accessibility, and ranked fairness. Revenue
design never outranks user trust or deterministic competitive integrity.

See revenue model, fairness, store items, ads policy, BMC, and future premium
documents in this folder.
