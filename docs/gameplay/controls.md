# Controls

- Drag anywhere on the rendered table to set a normalized aim direction from
  the cue ball.
- Adjust the power slider from 10–100%; physics maps it to a bounded cue speed.
- Select tip offset on the circular spin pad: horizontal is side English,
  vertical is top/follow or back/draw spin.
- Tap Shoot. Input is rejected while balls move or when the cue ball is not
  available.
- Reset rack requires confirmation. Android back exits through navigation.

Settings provides 0.5–2.0 aim sensitivity storage, left-handed control order,
haptics, sound/music preferences, and reduced motion. Aim sensitivity is stored
but fine-grained scaling is not yet applied to drag deltas; this remains a known
beta integration task rather than a false capability claim.

Future accessibility controls include buttons/D-pad fine aim, optional aim lock
in practice, ball-in-hand placement, called pocket, zoom where useful, and
configurable accessible shot confirmation.
