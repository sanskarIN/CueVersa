# Licensing guide

CueVerse repository code and original project assets use Apache License 2.0
unless a file says otherwise. Apache-2.0 provides broad use/modification/
distribution rights, an explicit patent grant, notice requirements, and no
warranty. Redistribution must retain required license/notices and mark modified
files where the license requires.

Third-party components retain their own compatible licenses. See `NOTICE` and
`THIRD_PARTY_NOTICES.md`. Dependency acceptance requires verified license text,
not a package-page guess. Strong-copyleft, source-available, field-of-use,
noncommercial, no-derivatives, unknown, or nonredistributable terms require
maintainer/legal review before inclusion.

Trademarks are separate from copyright licenses. The Apache license does not
grant permission to misrepresent endorsement or copy protected commercial-game
identity. “Buy Me a Coffee” identifies an external service; its logo is not
bundled.

This is engineering documentation, not legal advice. Legal templates require
qualified review before commercial publication.
