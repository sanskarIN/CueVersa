# Accessibility

## Implemented foundations

- English/Hindi semantics for brand, BMC, table ball count, spin, buttons, and
  progress.
- Material minimum sizing, visible focus/press states, scalable system text,
  responsive grids/lists, and no fixed text-height containers.
- System/light/dark theme, explicit high-contrast mode, reduced motion, haptics
  toggle, sound toggles, left-handed controls, and adjustable aim sensitivity.
- Ball numbers and solid/stripe geometry reinforce color; game state uses text
  labels rather than color alone.
- Aim, power, and spin can be adjusted separately. AI/ranked concepts do not
  sell enhanced guides.

## Manual release matrix

Test TalkBack traversal/order/actions, 200% text, display size, bold text,
English/Hindi long labels, portrait/landscape, tablet/foldable widths, high
contrast, dark mode, color-vision simulation, Switch Access, keyboard/focus on
supported form factors, reduced motion, and haptics/sound disabled.

The painted table is currently exposed as one semantic image plus external
controls. Per-ball exploratory semantics and non-touch fine-aim controls remain
beta tasks before claiming full motor-accessibility parity.
