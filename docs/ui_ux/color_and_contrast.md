# Color and contrast

Theme colors are generated into semantic ColorScheme roles. High-contrast mode
uses darker/lighter primaries, black/white surfaces, stronger 2 px outlines,
and retains text/icon/state labels.

Pool balls use conventional recognizable families but also display numbers and
stripe geometry. Solids/stripes and turn state are textual. Focus, disabled,
error, and selection states must not depend on hue alone.

Before release, measure WCAG contrast for text/icons/components in light, dark,
and high-contrast variants; simulate common color-vision deficiencies; verify
table/ball separation under low brightness; and capture exceptions with a
remediation owner. Decorative trajectory lines are not sole input feedback.
