# Changelog

All notable changes are recorded here using Keep a Changelog conventions. The
project uses semantic versioning once a stable public API exists.

## [Unreleased]

### Added

- Flutter Android application with CueVerse branding and responsive Material 3
  presentation.
- Deterministic 240 Hz pool simulation with collisions, rails, pockets,
  rolling/sliding response, top/back spin, and side English.
- Configurable 8-ball and 9-ball rules engines.
- Practice, six-level AI, and local pass-and-play modes.
- English and Hindi localization, high contrast, reduced motion, left-handed
  controls, semantics, haptics, and deep grouped Settings.
- Local-first progress/statistics and optional BMC support experience.
- Physics, rules, AI, persistence, localization, and widget regression tests.

### Security

- Cleartext Android network traffic disabled.
- App backup/transfer excludes local game preferences and databases.
- No signing keys, API credentials, analytics, ads, purchases, or remote
  services are included.
